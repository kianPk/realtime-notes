# Realtime Notes

Shared notepad — **Socket.IO** + **Vue 3**.

[![Vue](https://img.shields.io/badge/vue-3-42b883?style=flat-square&logo=vue.js&logoColor=white)](./web)
[![Socket.IO](https://img.shields.io/badge/realtime-socket.io-010101?style=flat-square)](./server)
[![License: MIT](https://img.shields.io/badge/license-MIT-0f1a22?style=flat-square)](./LICENSE)

## Quick start

```bash
cd server && npm i && npm start   # :4200
cd web && npm i && npm run dev    # :5175
```

Open two browser tabs → same room → type. Updates stream live.
